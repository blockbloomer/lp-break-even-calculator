# LP「包赚」计算器首版

## 关键决策

- 用户已确认：独立本地网页、手填 APR、币／稳定币、全稳定币进出、按区间或配比两种方式联动。不公开部署、不连接钱包。
- 主结果为覆盖区间内最不利退出情况所需的有效做市时间。不能将截图的“半仓乘跌幅”当作 LP 实际损失。
- 本金定义为净入池价值；开仓换币成本额外计算，总资金需求预留双程 gas。
- 开仓换币必须 gross-up：净波动币价值除以组合保留率后，才是买足所需币量的花费。退出按实际波动币金额扣兑换成本。
- 手续费兑现损耗默认按全部费用需兑换估计，可手动覆盖，只减净时费。所有百分比在输入中按百分数表示，在计算中除以 100。
- 配比为初始美元价值占比；固定下限存在最大可行币占比。反算上限先验证正分母，不能对负分母平方后继续使用。

## 数值实现

- 使用相对现价归一化和有理化平方根差，避免极窄区间出现消减误差。
- 现价本金保持精确等于 C；区间外数量截断，估值仍用实际价格。
- 1% 样例独立 60 位 Decimal 核对：损失 37.4692189619467067，回本 0.6564607162133063 小时。
- 2% 标准样例：零成本回本 2.6237515282 小时；默认含成本回本 3.8169995472 小时。

## 首版验证

- 15 项自动数学测试通过；独立审计 1200 组随机性质核验通过。
- 浏览器验证：零 APR、空本金、50:50 上沿反算、99.1% 不可行配比、自定义兑现损耗 100%、零成本样例、Tab 焦点流。
- 清空现价再填写 200 后，上下限正确保持在 196–204；保留最后有效现价作为比例基准，避免中间空值破坏联动。
- 桌面 1440×1000、手机 390×844 检查；手机单栏无横向溢出，图表使用独立紧凑坐标系。第一轮发现的小字对比度和图表缩小问题已修正。
- 本地运行入口为 `npm run dev`，地址 http://127.0.0.1:5188/；生产预览 `npm run preview`，地址 http://127.0.0.1:4188/。

## 边界

理论区间，不对齐 tick；稳定币视为一美元。费收以退出时美元等值估计，不模拟费率变化、手续费币持有价格变化或未来价格路径。资金与参数不持久化，刷新恢复示例。
