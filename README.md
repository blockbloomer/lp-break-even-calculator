# LP「包赚」计算器

本地使用的集中流动性 LP 成本覆盖计算器：调好本金、实际涨跌区间、当前区间实时 APR、本次买币比例及进出场成本，计算需要多久的有效做市手续费，才能覆盖全部美元本金损失、换币磨损和 gas。

## 启动

需要 Node.js 22.13 或更新版本。

```sh
npm ci
npm run dev
```

打开 [本地计算器](http://127.0.0.1:5188/)。服务只监听本机，终端按 Ctrl+C 停止。端口被占用时明确报错，不自动换端口。

```sh
npm run build
npm run preview
```

构建预览为 [127.0.0.1:4188](http://127.0.0.1:4188/)。不公开部署、不连接钱包、不发送交易、不读取行情；参数保留在当前页面，刷新恢复示例，字体随项目提供。

## 怎么用

常用参数全部使用滑块，并提供本金、年化、对称区间及买币比例快捷选项；也可以点当前数字精确修改。超出默认滑块范围的有效数值会扩展滑块显示范围。

- **净入池本金：**实际进入 LP 的美元价值，不含本次配平和 gas 成本，可包含已持资产的开仓时价值。
- **当前区间实时 APR：**直接用用户自己当前仓位、当前区间的手续费年化，5000% 填 5000。区间和买币比例不会再次放大或缩小 APR。实际换了区间时，需要填入新仓位对应的 APR。
- **允许下跌／上涨：**分别相对开仓价设置，可不对称。无需填写币价绝对值；底层将开仓价格归一化为 1。
- **开仓买币比例：**只用于本次换币成本估算。1:9 对应买币 10%、其余资产 90%；5000 美元本金需要买到价值 500 美元的币，实际支出另加损耗。这个比例不反算区间，也不决定 CLMM 库存，剩余资产视为已经就绪。
- **Gas：**进场和退出分别填写完整流程的总美元成本，合并交易不要重复计算。
- **兑换费与成交磨损：**分开填写。成交磨损是预估实际滑点和价格冲击，不是钱包里的滑点容忍度。开仓按本次要买币的净金额反推支出；退出按 LP 当时需要卖出的波动币金额计费。
- **手续费兑现损耗：**高级设置默认跟随退出的组合损耗，保守假定全部手续费都要换币，可手动覆盖。只减少手续费净收入，不重复加入本金成本。

## 覆盖什么成本

用户最终确认口径：**退出时美元本金不亏**，不仅仅是相对持币基准的无常损失。

```text
美元本金损失 = 币价下跌本身的损失 + LP 相对持币额外产生的无常损失
待覆盖金额 = 美元本金损失 + 本次开仓换币损耗 + 退出换币损耗 + 双程 gas
每小时净手续费 = 本金 × APR ÷ 100 ÷ 8760 ×（1 − 手续费兑现损耗率）
成本覆盖时间 = max(0, 待覆盖金额) ÷ 每小时净手续费
```

币价下跌损失以开仓时真实 LP 配比的持币基准计算。LP 两币数量根据实际上下区间按 Uniswap V3 曲线变化，不假设永远 1:1。无常损失已经包含在总本金损失中，只拆开展示，不重复扣除。

记净入池本金为 C、本次净买币比例为 b、进场组合保留率为 `kin=(1-fin)(1-sin)`，则开仓支出为 `C*b/kin`，开仓损耗为 `C*b*(1/kin-1)`。这里 b 为小数。

`src/lib/parameters.ts` 将百分数控件映射到归一化价格；`src/lib/calculator.ts` 的纯函数 `calculateLPBreakEven(input)` 输出成本、美元损失分解、费用速度和三个退出情景。`entryBuyPercent` 采用百分数，例如 10 表示 10%。历史绝对区间及配比反算数学辅助函数仍保留，网页不再提供该输入方式。

## 假设边界

- 波动币／稳定币集中流动性，稳定币按 1 美元估值；退出全部换回稳定币。
- 主结果按下沿退出计算：在固定费用率下，它是区间内美元退出净值最低的位置。
- 时间指累计有效做市时间，不是预计多久触边。出区间期间不计手续费；跌破下沿继续下跌可能继续亏损，不在所设边界内。
- 输入的实时 APR 作为后续费收假设，不保证保持；手续费按退出时美元等值估计，不复投、不含奖励、不模拟手续费币持有期间价格变化。
- 使用理论连续价格区间，不对齐 tick，不生成交易或签名；已有资产的历史买入成本不计入本次测算。
- 价格范围决定 LP 库存，本次买币比例是用户指定的配平成交成本基数；不验证真实链上操作是否能按此预算完成配平。

公式来源：[Uniswap V3 白皮书](https://app.uniswap.org/whitepaper-v3.pdf)、[Uniswap 数学说明](https://blog.uniswap.org/uniswap-v3-math-primer-2)。

| 0% | $0 | $0 | $98.5645 | $28.4247 | 3.4676 小时 |
| 10%（1:9） | $500 | $2.0065 | $100.5710 | $28.4247 | 3.5381 小时 |
| 50%（1:1） | $2,500 | $10.0326 | $108.5971 | $28.4247 | 3.8205 小时 |

零执行成本时，同一 ±2% 区间美元本金损失为 74.8788，其中币价下跌损失约 49.5025、无常损失约 25.3763；每小时手续费 28.5388，覆盖需 2.6238 小时。只覆盖无常损失及费用并不能保证美元本金不亏。

显示时间约至分钟或秒、账本金额约至美分，计算使用未舍入值；单行显示金额相加可能相差一美分。
