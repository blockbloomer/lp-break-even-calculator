# LP「包赚」计算器

本地使用的集中流动性 LP 回本测算网页。输入本金、手续费 APR、价格区间、配比与进出场成本，估算覆盖区间内最不利退出情况所需的有效做市时间。

技术方案：React、TypeScript、Vite；独立计算引擎，不连接钱包或发送交易。

## 启动

需要 Node.js 22.13 或更新版本。

```sh
npm ci
npm run dev
```

打开 [本地计算器](http://127.0.0.1:5188/)。服务只监听本机；终端按 Ctrl+C 停止。端口被占用时明确报错，不自动换端口。

构建后也可以在本机预览：

```sh
npm run build
npm run preview
```

预览地址为 [127.0.0.1:4188](http://127.0.0.1:4188/)。本项目没有公网部署、后台采集、账号或数据库；参数只保留在当前页面，刷新恢复示例。字体随项目提供，计算过程不请求第三方接口。

## 如何填写

- **净入池本金：**实际进入 LP 的美元价值，不含换币成本和 gas。结果另列总资金需求，其中预留退出 gas。
- **手续费 APR：**针对当前仓位及区间的预估单利手续费年化。例如 5000% 填 `5000`；不含币价涨跌和奖励，不复投。不要用全池平均 APR 直接代替特定区间仓位的费收。
- **当前币价：**一个波动币值多少稳定币。稳定币按一美元估值。改现价时保持当前上下限相对幅度；手动修改上下限则调整区间。
- **价格区间与配比：**可以填上下限自动算初始美元配比，也可以填波动币占比和下限反算上限。两种方式切换会保留有效仓位，不把区间和配比当作三个独立参数。
- **Gas：**进场、退出分别填整个操作流程的总美元成本，合并交易不重复计数。
- **兑换费率：**仅对真正发生兑换的资产计费，不能把 LP 存入／撤出本身再当作一次全本金兑换。
- **成交磨损：**预估实际滑点与价格冲击损失，不是钱包设置的滑点容忍度。
- **手续费兑现损耗：**高级设置默认跟随退出的组合损耗，保守假定全部手续费都需要换币。可以独立填写；这个损耗只作用于手续费收入。

## 模型与假设

只覆盖 Uniswap V3 类集中流动性、一个波动币与一个稳定币。默认全稳定币进场、退出全部换回稳定币，使用理论连续价格区间，不生成 tick 或交易参数。

记净入池本金为 C，初始波动币价值比例为 w；进出场兑换保留率分别为 `kin=(1-fin)(1-sin)`、`kout=(1-fout)(1-sout)`，各费率使用小数。

```text
开仓换币损耗 = w × C × (1 / kin − 1)
退出净值(P) = kout × P × 波动币数量(P) + 稳定币数量(P)
待覆盖金额(P) = C + 开仓换币损耗 + 双程 gas − 退出净值(P)
每小时净手续费 = C × (APR / 100) / 8760 × (1 − 兑现损耗率)
回本时间(P) = max(0, 待覆盖金额(P)) / 每小时净手续费
```

币数量随价格按集中流动性公式改变。数量在上下沿截断，价格估值使用真实退出价；跌破下限后继续下跌仍会继续亏损。相同成本率下，区间内退出净值随币价单调上升，因此主结果取下沿。

“回本时间”指累计有效做市时间，不预测多久触边。出区间不累计手续费。APR 按预估退出时美元等值计价，手续费币在持有期间的价格变化不建模；缩窄区间不会自动提高 APR。

开仓损耗按买足净入池币量反推实际花费。两次成本按顺序扣减，而非简单相加费率。LP 数量变化已包含本金损失，不能再额外扣一次无常损失。

源码入口：`src/lib/calculator.ts` 导出 `calculateLPBreakEven(input)`。成功返回实际配比、初始数量、成本、手续费速度与三个退出情景；错误返回字段错误。存在待覆盖金额且净手续费为零时，回本时间为 `null`，界面显示“当前参数下无法回本”。

公式来源：[Uniswap V3 白皮书](https://app.uniswap.org/whitepaper-v3.pdf)、[Uniswap 数学说明](https://blog.uniswap.org/uniswap-v3-math-primer-2)。

## 验证

```sh
npm test
npm run typecheck
npm run lint
npm run build
```

15 项自动测试覆盖价格与数量、配比反算、费用仅扣一次、有效／无效参数、零收益、100% 手续费兑现损耗、资本缩放和极窄区间稳定性。

已核对样例：

| 净入池本金 | 区间 | APR | 成本条件 | 每小时净手续费 | 待覆盖金额 | 有效做市回本时间 |
|---|---|---|---|---|---|---|
| $5,000 | ±2% | 5000% | 零成本 | $28.5388 | $74.8788 | 2.6238 小时 |
| $5,000 | ±2% | 5000% | 双程 gas 各 $2，兑换费各 0.3%，成交磨损各 0.1%，默认兑现损耗 | $28.4247 | $108.4972 | 3.8170 小时 |
| $5,000 | ±1% | 10000% | 零成本 | $57.0776 | $37.4692 | 0.6565 小时 |

显示的时间约至分钟或秒，账本金额约至美分，计算过程使用未舍入值，因此单行显示值相加可能相差一美分。
