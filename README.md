# LP「包赚」计算器

在浏览器内运行的集中流动性 LP 成本覆盖计算器：调好本金、实际涨跌区间、当前区间实时 APR、本次买币比例及进出场成本，计算需要多久的有效做市手续费，才能覆盖全部美元本金损失、换币磨损和 gas。

线上入口：[LP「包赚」计算器](https://blockbloomer.github.io/lp-break-even-calculator/)。

## 启动

需要 Node.js 22.13 或更新版本。

```sh
npm ci
npm run dev
```

打开 [本地计算器](http://127.0.0.1:5188/)。服务只监听本机，终端按 Ctrl+C 停止。端口被占用时明确报错，不自动换端口。

```sh
npm run build
npm run preview
```

构建预览为 [127.0.0.1:4188](http://127.0.0.1:4188/)。计算在访问者自己的浏览器内完成，不连接钱包、不发送交易、不读取行情；参数保留在当前页面，刷新恢复示例，字体随项目提供。

## GitHub Pages 发布

仓库的 `main` 分支更新后，GitHub Actions 会安装锁定依赖、运行测试、类型检查和 lint、构建静态页面，再部署到 GitHub Pages。也可以在 Actions 中手动运行 `Deploy calculator to GitHub Pages`。

首次使用时在仓库 Settings → Pages 将 Source 设置为 GitHub Actions。工作流为 `.github/workflows/pages.yml`，构建目录为 `dist/`；Vite 使用相对资源路径，同时支持本机预览和仓库子目录。无需配置自定义密钥。需要撤下网站时，可在 Pages 设置中取消发布；代码仍保留在仓库。

## 怎么用

常用参数全部使用滑块，并提供本金、年化、对称区间及买币比例快捷选项；也可以点当前数字精确修改。除 APR 固定封顶 100,000% 外，超出默认滑块范围的有效数值会扩展滑块显示范围。APR 精确输入超过上限时显示错误并暂停计算。

- **净入池本金：**实际进入 LP 的美元价值，不含本次配平和 gas 成本，可包含已持资产的开仓时价值。
- **当前区间实时 APR：**直接用用户自己当前仓位、当前区间的手续费年化，5000% 填 5000。区间和买币比例不会再次放大或缩小 APR。实际换了区间时，需要填入新仓位对应的 APR。
- **允许下跌／上涨：**分别相对开仓价设置，可不对称。无需填写币价绝对值；底层将开仓价格归一化为 1。
- **开仓买币比例：**只用于本次换币成本估算。1:9 对应买币 10%、其余资产 90%；5000 美元本金需要买到价值 500 美元的币，实际支出另加损耗。这个比例不反算区间，也不决定 CLMM 库存，剩余资产视为已经就绪。
- **Gas：**进场和退出分别填写完整流程的总美元成本，合并交易不要重复计算。
- **交易磨损：**将兑换手续费、实际滑点和价格冲击统一估算成一个总损耗率，进场、退出各设置一个。不是钱包里的滑点容忍度。开仓按本次要买币的净金额反推支出；退出按 LP 当时需要卖出的波动币金额计算，不再拆分或叠加两次损耗。
- **手续费兑现损耗：**高级设置默认直接跟随退出交易磨损，保守假定全部手续费都要换币，可手动覆盖。只减少手续费净收入，不重复加入本金成本。

## 覆盖什么成本

用户最终确认口径：**退出时美元本金不亏**，不仅仅是相对持币基准的无常损失。

```text
美元本金损失 = 币价下跌本身的损失 + LP 相对持币额外产生的无常损失
待覆盖金额 = 美元本金损失 + 进场交易磨损 + 退出交易磨损 + 双程 gas
每小时净手续费 = 本金 × APR ÷ 100 ÷ 8760 ×（1 − 手续费兑现损耗率）
成本覆盖时间 = max(0, 待覆盖金额) ÷ 每小时净手续费
```

币价下跌损失以开仓时真实 LP 配比的持币基准计算。LP 两币数量根据实际上下区间按 Uniswap V3 曲线变化，不假设永远 1:1。无常损失已经包含在总本金损失中，只拆开展示，不重复扣除。

记净入池本金为 C、本次净买币比例为 b、进场交易磨损率为 m，则开仓支出为 `C*b/(1-m)`，开仓磨损为 `开仓支出*m`。这里 b、m 为小数。退出交易磨损为 `当时卖币金额*退出磨损率`。例如净买币目标 500 美元、进场磨损 0.4%，实际支出约 502.0080 美元，其中磨损约 2.0080 美元。

`src/lib/parameters.ts` 将百分数控件映射到归一化价格；`src/lib/calculator.ts` 的纯函数 `calculateLPBreakEven(input)` 输出成本、美元损失分解、费用速度和三个退出情景。`entryBuyPercent` 采用百分数，例如 10 表示 10%。历史绝对区间及配比反算数学辅助函数仍保留，网页不再提供该输入方式。

## 假设边界

- 波动币／稳定币集中流动性，稳定币按 1 美元估值；退出全部换回稳定币。
- 主结果按下沿退出计算：在固定费用率下，它是区间内美元退出净值最低的位置。
- 时间指累计有效做市时间，不是预计多久触边。出区间期间不计手续费；跌破下沿继续下跌可能继续亏损，不在所设边界内。
- 输入的实时 APR 作为后续费收假设，不保证保持；手续费按退出时美元等值估计，不复投、不含奖励、不模拟手续费币持有期间价格变化。
- 使用理论连续价格区间，不对齐 tick，不生成交易或签名；已有资产的历史买入成本不计入本次测算。
- 价格范围决定 LP 库存，本次买币比例是用户指定的配平成交成本基数；不验证真实链上操作是否能按此预算完成配平。

公式来源：[Uniswap V3 白皮书](https://app.uniswap.org/whitepaper-v3.pdf)、[Uniswap 数学说明](https://blog.uniswap.org/uniswap-v3-math-primer-2)。

```sh

```

自动测试覆盖本金守恒、损失分解、交易磨损只扣一次、收入兑现跟随与独立设置、配比与区间数学、买币比例的独立性、百分比映射、APR 上限、缺失参数、零收益、100% 兑现损耗及极窄区间精度。

当前示例：本金 5000、±2%、APR 5000%、双程 gas 各 2 美元、进出场交易磨损各 0.4%、自动兑现损耗：

| 本次买币比例 | 净买币金额 | 入场损耗 | 总待覆盖 | 每小时净手续费 | 覆盖时间 |
|---|---|---|---|---|---|
| 0% | $0 | $0 | $98.5792 | $28.4247 | 3.4681 小时 |
| 10%（1:9） | $500 | $2.0080 | $100.5873 | $28.4247 | 3.5387 小时 |
| 50%（1:1） | $2,500 | $10.0402 | $108.6194 | $28.4247 | 3.8213 小时 |

零执行成本时，同一 ±2% 区间美元本金损失为 74.8788，其中币价下跌损失约 49.5025、无常损失约 25.3763；每小时手续费 28.5388，覆盖需 2.6238 小时。只覆盖无常损失及费用并不能保证美元本金不亏。

显示时间约至分钟或秒、账本金额约至美分，计算使用未舍入值；单行显示金额相加可能相差一美分。
